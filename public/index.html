    How to read it

    DOM city

    Every box is an HTML element. In the City view its footprint is proportional to how many descendants it contains and its height to how deeply it is nested. Tall, thin towers = chains of unnecessary wrapper divs. The Page layout view uses the real pixel positions.

    Network space

    Every planet is a domain; the glowing core in the middle is the site itself. Satellites are loaded resources and their size reflects the bytes downloaded. Flowing lines show one domain loading resources from another (the initiator).
